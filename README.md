# sql-learning
> 求职方向：数据运营｜MySQL业务SQL复习实操仓库

## 仓库简介
MySQL SQL复习与电商业务查询练习，包含基础查询、多表联查、聚合统计、窗口函数，为电商复购数据分析项目做SQL技能储备，覆盖数据运营面试高频SQL考点。

## 目录
- Day01 基础SELECT查询：WHERE、LIMIT、比较运算符
- Day02 排序与去重：ORDER BY、DISTINCT
- Day03 分组聚合：GROUP BY、聚合函数
- Day04 多表JOIN连接：INNER/LEFT JOIN
- Day05 CASE WHEN 条件判断，业务指标统计
- Day06 窗口函数：row_number/rank，用户分层、复购统计
- Day07 综合业务面试题：电商订单、用户行为分析

## 技术栈
MySQL 8.0
